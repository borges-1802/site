# Portfólio - João Victor Borges

Site pessoal onde reúno meus trabalhos como **desenvolvedor full stack** e **UX/UI designer**. Sou estudante de Ciência da Computação na UFRJ, com foco em engenharia de dado, IA e desenvolvimento web.

## O que tem no site

- **Conhecimentos** - as tecnologias que uso no dia a dia, organizadas por área (frontend, backend, dados, design e ferramentas).
- **Experiência** - linha do tempo com estágio, iniciações científicas, monitorias, empresa júnior e liderança estudantil.
- **Projetos de desenvolvimento** - cada projeto principal tem uma página própria com contexto, meu papel, stack, decisões técnicas, galeria de telas e resultado.
- **Projetos de design** - identidade visual, UX/UI e social media, com o portfólio completo em PDF.
- **Contato** - e-mail, LinkedIn, GitHub e Lattes.

O site está em **português e inglês** e tem **tema claro e escuro**.

## Tecnologias

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 - gerado como site estático.

## Rodar localmente

```bash
npm install
npm run dev
```
